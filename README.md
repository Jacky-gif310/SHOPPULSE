# ShopPulse — Comparative Customer Feedback Analytics

A web-based customer feedback analytics platform that collects shopping experiences and helps compare customer satisfaction across different online and retail shopping platforms.

## Overview

**ShopPulse** allows users to share their shopping experiences and provides comparative analytics across platforms such as Jumia, Amazon, Kilimall, Carrefour, AliExpress, eBay, and Oraimo.

The platform turns customer responses into visual insights that can help consumers, researchers, and small businesses better understand customer expectations and areas for improvement.

## Features

* Customer survey data collection
* Support for multiple shopping platforms
* Custom platform entry
* Comparative customer experience analysis
* Dynamic analytics dashboard
* Interactive charts using Chart.js
* Customer satisfaction and recommendation analysis
* Delivery, pricing, product quality, and customer support analysis
* Shared online survey database
* User login and registration interface
* Responsive web interface

## Key Analytics

ShopPulse analyzes customer responses across areas including:

* Overall experience
* Product satisfaction
* Delivery experience
* Delivery speed
* Pricing fairness
* Customer support
* Shopping frequency
* Likelihood of recommending a platform
* Customer improvement suggestions

## Architecture

The application uses a lightweight web architecture:

**Frontend**

* HTML
* CSS
* JavaScript
* Chart.js

**Backend**

* Supabase
* PostgreSQL database
* Supabase API

The frontend is hosted using GitHub Pages, while Supabase provides the shared online database that allows survey responses to be accessed across different browsers and devices.

## Project Purpose

ShopPulse was developed as an independent customer-feedback analytics project to demonstrate how web technologies, data analysis, and visualization can be used to transform survey responses into meaningful comparative insights.

The project focuses on the relationship between **customer experiences, platform comparison, data analytics, and decision-making**.
